# DocThay2 — Portfolio landing (Next.js)

Personal / professional **landing page** built with **Next.js**, **TypeScript**, **Tailwind**, and **Redux Toolkit**, with a particle background and sections for hero, about, projects, and contact.

Author: [Erick Vargas](https://github.com/erickorso)

## Stack

- **Next.js** · **React** · **TypeScript**
- **Tailwind CSS**
- **Redux Toolkit**
- Particle UI (`@tsparticles` / tsparticles React)

## Features

- Single-page marketing layout (Header · Hero · About · Projects · Contact)
- Animated particle background
- Client state via Redux Toolkit
- App Router structure under `src/app`

## Run

```bash
yarn   # or npm install
yarn dev
```

```bash
yarn build
yarn start
```

Open [http://localhost:3000](http://localhost:3000).
